# Design Context

## Users and tasks
Wayne manages posts, pages, projects, media, and newsletters on his personal developer-community site. Dashboard controls must be understandable to a new developer and usable on phones and tablets as well as desktop.

## Visual direction
Preserve the existing restrained editorial interface, four themes, CSS variables, compact radii, and clear type hierarchy. No purple, emoji, or decorative redesign. Group related controls, place explanatory labels above full-width fields, and retain visible save actions.

## Principles
- Readable labels and reachable controls before density.
- Reflow at constrained widths rather than clipping content.
- Keyboard and touch access share the same meaningful actions.
- Keep UX, developer maintenance, and agent-readable semantics aligned.

Context drawn from the user's project instructions and responsive maintenance request.
