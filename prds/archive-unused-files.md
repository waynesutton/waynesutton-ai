# Archive unused legacy files

Created: 2026-08-16 07:45 UTC
Last Updated: 2026-08-16 07:55 UTC
Status: Done

## Problem

The repo was forked from markdown.fast and still carries files for two workflows this site no longer uses:

1. Netlify hosting (the site deploys with Convex static hosting via `npm run deploy`)
2. npm package publishing (markdown.fast published `convex-fs` and fork tooling; this personal site does not publish anything)

There are also stray zero-byte or accidental files in the repo root created by mistyped shell commands (`npx`, `markdown-site@1.0.0`, `SYNC_ENV=production` which contains captured sync output).

## Proposed solution

Move confirmed-unused files into `archive-for-delete/` for review before permanent deletion. Remove package.json entries that point at archived files.

## Files to archive

| File | Reason safe |
|------|-------------|
| `netlify/` (edge-functions) | Only referenced by `netlify.toml`; site uses Convex static hosting |
| `netlify.toml` | Netlify build config, unused |
| `FORK_CONFIG.md` | Fork setup guide for markdown.fast forks |
| `fork-config.json.example` | Input for `scripts/configure-fork.ts` |
| `scripts/configure-fork.ts` | Fork wizard; only wired to `npm run configure` |
| `convex-virtual-fs/` | Local source of the `convex-fs` npm package. App imports `convex-fs` from node_modules (see `convex/fs.ts`, `convex/http.ts`, `convex/convex.config.ts`), not this folder. Not publishing to npm. |
| `convex-doctor-output.json` | Zero-byte stale output file (`convex-doctor.toml` stays, it holds active suppressions) |
| `SYNC_ENV=production` | Accidental file from a shell redirect mistake |
| `npx` | Zero-byte accidental file |
| `markdown-site@1.0.0` | Zero-byte accidental file |
